# Bappa Agent knowledge sources

The first version intentionally uses a small, reviewable local knowledge bank instead of inventing mythology at runtime.

- **Ganesha’s common associations** — wisdom, prudence, beginnings, and invocation before auspicious work: [1911 Encyclopaedia Britannica entry via Wikisource](https://en.wikisource.org/wiki/1911_Encyclop%C3%A6dia_Britannica/Ganesa).
- **Festival context** — Ganesh Chaturthi / Vinayaka Chavithi and its traditional ten-day observance: [Ministry of Culture, Government of India annual report](https://www.indiaculture.gov.in/sites/default/files/Annual_Reports_Organizations/Annual_Report_20-21_06042022.pdf).
- **Traditional narrative variants** — birth, elephant head, tusk, and other कथा are treated as religious traditions with regional variations, not as one historically verified account. For a museum-curated visual overview, see [Google Arts & Culture / British Museum: Celebrating Ganesha](https://artsandculture.google.com/story/celebrating-ganesha-the-british-museum/jwWxaGE_2ddqIg?hl=en).

The agent adds a local-time greeting from the visitor’s device clock. It does not currently claim to know live festival timings, puja timings, weather, or news. Those can be added later with explicit location and calendar sources.
